# VeeR-EH2 与 CRC FPGA 工程

实际工程根目录位于 [`Cores-VeeR-EH2-main/`](Cores-VeeR-EH2-main/README.md)。该目录包含 VeeR-EH2 RTL、Synplify 工程、仿真文件，以及面向 VeriTiger V19P 的双 hart 指令 CRC/日志归约 FPGA 实现。

板级 CRC 工程的构建、验证与比特流说明见 [`Cores-VeeR-EH2-main/log_eh2_crc_fpga/README.md`](Cores-VeeR-EH2-main/log_eh2_crc_fpga/README.md)。已实现比特流位于 `Cores-VeeR-EH2-main/log_eh2_crc_fpga/vivado_build/output/eh2_crc_fpga_top.bit`。
